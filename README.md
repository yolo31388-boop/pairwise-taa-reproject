# pairwise-taa-reproject

镜头慢推时栅栏边缘像水波一样抖，快速转身后整帧拖出残影，雨丝变成一串鬼影：TAA 的抖动序列按帧号循环，暂停菜单打开后帧号停住，画面固定在偏移位置；速度缓冲只写相机运动，蒙皮角色和粒子没有运动矢量，重投影到错误位置；历史帧按当前像素直接取，深度和法线差异大的地方没有做邻域裁剪；去遮挡区域用上一帧颜色填补，角色轮廓后面拖出旧背景；alpha test 材质在历史帧里保留了上一帧的镂空形状，树叶边缘越拖越厚；HDR 亮度变化大时历史权重不降，闪光弹后整屏余亮；分辨率切换或 DLSS 开关后历史纹理没清，第一帧混入旧尺寸内容；动态物体和静态场景共用同一张历史，角色走过的地方地面被抹平；雨丝速度超过重投影范围，历史采样落到天空，出现长条鬼影；相机 cut 后没有重置历史，转场把两个镜头混在一起；UI 和字幕被写进场景颜色，重投影后文字边缘发糊；多相机分屏共用历史纹理，左右屏互相污染；锐化在 TAA 之前做，边缘抖动被放大。render/taa_reproject.py 是核心，tests/test_taa_reproject.py 15个红。要修的是：抖动序列；全量速度；邻域裁剪；去遮挡；alpha 材质；HDR 权重；分辨率重置；动静分离；超速抑制；cut 重置；UI 隔离；多相机隔离；锐化顺序。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
